ISSUE 1 -- CCSR/CCS column trailing spaces  [ACTIVE]
  Affects: X_train.parquet, X_test.parquet, final_dataset_clean.parquet
  Count:   183 columns have trailing spaces in their names
  Example: "10   " instead of "10", "100  " instead of "100"
  Cause:   preprocessing.ipynb strips in wrong order:
             df.columns.str.strip().str.replace("'", '')
           The quotes are the outermost characters so str.strip()
           removes nothing. After quote removal, spaces are exposed
           but no second strip is called.
  Fix:     Swap order to:
             df.columns.str.replace("'", '').str.strip()
  Impact:  No effect on model accuracy (sklearn ignores col names).
           Will cause ugly labels in SHAP feature importance plots.

ISSUE 2 -- preprocessing.ipynb output does not match actual clean dataset  [ACTIVE]
  preprocessing.ipynb (built this session) produces 753 columns.
  Actual final_dataset_clean.parquet has 455 columns.
  The clean dataset was produced inline inside modeling_v2.ipynb,
  not by running preprocessing.ipynb. The two pipelines are out of sync.
  Differences:
    - preprocessing.ipynb fills NaN with UNKNOWN string
    - Actual clean dataset uses _missing suffix columns
    - preprocessing.ipynb keeps all 705 CCSR columns
    - Actual clean dataset drops 298 low-prevalence columns
  Impact:  preprocessing.ipynb output is never used by any downstream
           notebook. It is documentation of intent, not actual source.

  The json was written by the modeling script and is the authoritative

ISSUE 5 -- CCS ICD-9 column names are numeric-only  [LOW PRIORITY]
